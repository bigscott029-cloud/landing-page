In this folder is my index.html and thankyou.html codes that I use for my affiliates link to get my leads to my whatsapp or any other directives destination. It is hosted on render via github workflows. 
It currently holds tiktok pixels to ensure tracking, I want to add more custom delivery to it to track my leads and know how many visit, clicked button and got redirected, all useful data rather than just guesses and hope, something much more effective and without the use of a database involved (by that I mean something like supabase as I would like the page to still respond fast, people don't like to be kept waiting).

For the current build, here is the cloudflare ID needed:

This is somewhat how the functino would run:
Inside the Worker configuration:

[[d1_databases]]
binding = "DB"

database_name = "analytics"

database_id = "your_database_id"


Now inside your Worker:
env.DB
becomes the database.

Example:
await env.DB.prepare(
"SELECT * FROM visits"
).all();

That's all.

 
Create the tables inside the necessary file:
schema.sql

Example:
CREATE TABLE visits(
id INTEGER PRIMARY KEY AUTOINCREMENT,
visitor_id TEXT,
event TEXT,
page TEXT,
country TEXT,
city TEXT,
device TEXT,
browser TEXT,
os TEXT,
language TEXT,
timezone TEXT,
screen TEXT,
referrer TEXT,
utm_source TEXT,
utm_medium TEXT,
utm_campaign TEXT,
created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

Then wrangler should be configured to be able to run:
wrangler d1 execute analytics --file schema.sql
